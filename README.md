# 🏨 Hotel Management System

A Java-based Hotel Management System with a responsive web frontend. This project demonstrates essential Java programming concepts and basic hotel operations.

## 📌 Project Overview

The system helps manage hotel rooms, customers, bookings, check-in, check-out, and billing.

## ✨ Features

### Java Application
- Admin login
- Room management
- Customer registration and validation
- Room booking
- Bill calculation
- Booking records stored using file handling
- Booking notifications using multithreading

### Website Frontend
- Dashboard
- Room availability
- Customer registration
- Room booking
- Check-in and check-out
- Billing section
- Responsive interface

## ▶️ How to Run the Java Application

1. Install the Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal in the project directory.
4. Compile the Java files:

```bash
javac -d out src/*.java
```

5. Run the application:

```bash
java -cp out Main
```

**Demo login:**
- Username: `admin`
- Password: `1234`

## 🌐 How to Run the Website

1. Open the project in VS Code.
2. Open the `web` folder.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website currently uses browser Local Storage for its frontend demonstration. It is not yet connected to the Java application backend.
